# The-Wrap-Club
The Wrap Club (El Clásico) El favorito de la casa. 80 gramos de filete de pollo premium sobre una base de lechuga fresca, zanahoria rallada y cebolla morada. Coronador con cuadraditos de tomate y cebolla fresca que le dan el toque crujiente perfecto. Envuelto en una tortilla suave lista para llevar.
